💡 Key Automated Insights (from actual data)

Market Concentration
New Delhi = 57.4% of all restaurants. Top 3 cities hold 80%+.
Delivery Growth Opportunity
Only 25.7% adoption overall; Budget tier only 15.8% vs Mid-Range 41.3%.
Premium = Better Ratings
Budget avg: 3.24 | Luxury avg: 3.89. Clear positive price-quality gradient.
Moderate Vote-Rating Correlation
Pearson r = 0.313. Popular restaurants tend to be good, but not always.
Table Booking Differentiator
With booking: 3.59 avg rating | Without: 3.41 avg. An 18-point premium.
Unrated Restaurant Pool
22.5% (2,148) restaurants have zero rating — large platform data gap.
North Indian Dominates
3,960 restaurants (North Indian) vs 2,735 (Chinese) vs 1,986 (Fast Food).
International Leaders
Top-rated cities (min 10 restaurants): London (4.54), Rio de Janeiro (4.49), Orlando (4.48).

🚀 How to Run

Install dependencies

pip install -r requirements.txt

Run the main analysis script

python Chetan_Chaudhari_Zomato_Analysis.py

Launch Streamlit dashboard

streamlit run app/streamlit_app.py

Open Jupyter notebook

jupyter notebook notebooks/Chetan_Chaudhari_Zomato_Restaurant_Analytics.ipynb
